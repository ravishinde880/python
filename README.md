# Project Name:
Password Strength Checker

## Project Description:
A simple Python program that checks whether a password is strong or weak. It checks the password length and verifies the presence of uppercase letters, lowercase letters, numbers, and special characters. If the password is weak, the program provides suggestions for improving it.

## Technologies Used:
Python 3
String operations
Conditional statements
Functions
Basic Python built-in methods

## How to Run:
Install Python 3.
Save the code as password_strength_checker.py.
Open Terminal/Command Prompt.
Navigate to the folder containing the file.
Run:

## Output
Example weak password:
=== Password Strength Checker ===
Enter a password to check: hello123

Password Strength: WEAK
Suggestions to improve your password:
- Add at least one uppercase letter.
- Add at least one special character.
Example strong password:
=== Password Strength Checker ===
Enter a password to check: Hello123!

Password Strength: STRONG
Your password meets all the basic security requirements.
