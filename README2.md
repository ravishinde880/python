## Project Name:
Caesar Cipher Encryption Tool
## Project Description:
A Python program that encrypts and decrypts text using the Caesar Cipher technique. The user enters a message and selects a shift value (key). The program displays the original, encrypted, and decrypted text.
Technologies Used:
Python 3
String manipulation
Functions
Loops
ord() and chr()
Modular arithmetic
## How to Run:
Install Python 3.
Save the code as caesar_cipher.py.
Open Terminal/Command Prompt.
Navigate to the folder containing the file.
## Run:
python caesar_cipher.py
Enter the text and shift value.
